# GPQ

GPQ (Get Post Query) - мини проект для тестирования api.

Главная фишка — обход **CORS** ограничений браузера. Если слать запросы к чужим API прямо из браузера, он их заблокирует. Поэтому я сделал проксирование: фронтенд шлет запрос на наш бэкенд, а сервер на C# уже с помощью `HttpClient` делает реальный запрос к стороннему API и возвращает ответ. Для серверов правил CORS нет, поэтому всё работает без проблем.

Историю и список запросов на сервере не сохраняется — всё хранится в браузере (`localStorage`).

---

### Что использовал:
* **Blazor (.NET 10)** — фронтенд на Blazor WebAssembly (`GPQ.Client`) и бэкенд на ASP.NET Core (`GPQ`), интерактивный рендеринг в браузере (`InteractiveWebAssembly`).
* **Bootstrap 5 + Custom CSS** — для разметки и оформления. Стили лежат локально в проекте.
* **HttpClient / IHttpClientFactory** — на бэкенде для проксирования запросов на сторонние сервера.

---

### Как устроено:
* `Program.cs` — серверный код, там настроен эндпоинт `/api/proxy`, который принимает и пересылает запросы.
* `Home.razor` — страница приложения (интерфейс + выбор методов, параметров, заголовков и отправка запроса).
* `Models.cs` — модели данных для запросов и ответов (`RequestModel`, `ProxyRequest`, `ProxyResponse`).
* `App.razor` — каркас Blazor-приложения.
* `app.css` — стили (темная/зеленая тема, плашки методов, оформление таблиц параметров).

---

### Как запустить:

В терминале в корневой папке проекта запускаем бэкенд:

```bash
dotnet run --project GPQ
```

И открываем в браузере адреса из консоли (`http://localhost:5066` или `https://localhost:7066`).
